\chapter{SVM Classifier Evaluation}

\section{Experimental Setup}

We evaluated the Support Vector Machine (SVM) classifier across both registered gene expression datasets: GSE19804 (balanced lung cancer, 120 samples) and GSE42568 (imbalanced breast cancer, 121 samples). The evaluation employed a 5-fold stratified cross-validation strategy with balanced class weighting and a linear kernel ($C = 1.0$).

The experimental framework comprised two distinct tracks:
\begin{itemize}
    \item \textbf{Path A (Baseline):} Linear SVM trained on the full high-dimensional feature space ($p = 54,675$) without feature selection.
    \item \textbf{Path B (Optimised):} Linear SVM trained on a standardized $k = 20$ feature subset selected strictly \textit{inside} each training fold using \texttt{sklearn.pipeline.Pipeline}.
\end{itemize}

By placing the \texttt{FeatureSelector} inside the cross-validation pipeline, feature ranking and subset selection were computed exclusively on each training fold ($80\%$ of data), guaranteeing zero data leakage to the evaluation test fold ($20\%$ of data).

\subsection{Performance Analysis on GSE19804}
\begin{enumerate}
    \item \textbf{Optimal Classifier Performance:} \textbf{SVM-RFE (\texttt{wrapper\_svm})} achieved the highest overall classification performance across all metrics: **Accuracy = 96.67\%**, **MCC = 0.9346**, and **F1-Score = 96.66\%**.
    \item \textbf{Variance Reduction:} Applying SVM-RFE reduced metric variance by nearly $50\%$ compared to Path A baseline ($\sigma_{\text{ACC}}$ dropped from $6.85\%$ to $3.49\%$), producing a more robust and stable model.
    \item \textbf{Dimensionality Reduction:} SVM-RFE achieved superior accuracy while discarding $99.96\%$ of noise features (reducing $p = 54,675$ down to $k = 20$).
\end{enumerate}

\subsection{Path A Majority-Class Collapse vs Path B Recovery}

As shown in Table~\ref{tab:gse42568_svm_results}, Path A baseline on GSE42568 suffered complete majority-class collapse due to extreme dimensionality ($p=54,675$) and severe class imbalance ($86\%$ cancer). The raw SVM predicted all samples as cancer, yielding an inflated accuracy ($85.97\%$) but **$\text{MCC} = 0.0000$** and **Specificity = $0.0\%$** (total failure to identify normal samples).

Applying univariate $t$-test feature selection inside the CV folds (\texttt{path\_b\_filter\_ttest}) broke this trivial majority collapse, recovering a non-zero **MCC of $+0.1139$** and raising **Specificity to $53.33\%$**.

\section{Discussion and Summary}

The empirical evaluation leads to two major findings:
\begin{enumerate}
    \item **On Balanced Datasets (GSE19804):** Wrapper feature selection (SVM-RFE) effectively eliminates uninformative probe noise, enhancing classification accuracy to **$96.67\%$** and MCC to **$0.9346$** while achieving a $99.96\%$ reduction in feature space.
    \item **On Imbalanced Datasets (GSE42568):** Feature selection prevents models from collapsing to trivial majority-class predictors, enabling the recovery of true negative (normal) sample discrimination.
    \item **Leakage Prevention:** Embedding feature selection strictly within cross-validation folds via scikit-learn \texttt{Pipeline} ensures rigorous, unbiased validation of high-dimensional genomic classifiers.
\end{enumerate}
