\chapter{Results and Discussion}

\section{Data Characteristics}

The primary feature-selection run used the GSE19804 lung-cancer dataset after preprocessing. The data matrix contained 120 samples and 54,675 probes, with a balanced class distribution of 60 cancer and 60 normal samples. This is an extreme high-dimensional setting, with a probe-to-sample ratio of more than 450:1.

\section{Feature-Selection Outcomes on GSE42568}

A second feature-selection run was completed for GSE42568 after the updated pipeline was finalised. In that run, the filter methods were executed without an explicit p-value cutoff in the CLI, so the resulting outputs reflect the default compact selection behavior (target size 20) rather than a threshold-driven subset. The selected probe lists for GSE42568 are stored in the project results directory and contain 20 probes for each retained method: Welch's t-test, ANOVA, SVM-RFE, Random-Forest importance, and LASSO. When a suitable p-value threshold is chosen, the same workflow should be rerun with the corresponding CLI argument to obtain the broader p-value-based selections.

\section{Feature-Selection Outcomes on GSE19804}

The main result of the updated pipeline is that the filter-based selectors behave differently from the wrapper and embedded selectors because they use a p-value rule rather than a fixed top-$k$ rule. Under a permissive threshold of $p \leq 0.05$, the filter methods retained a very large fraction of the probe space:

\begin{itemize}
    \item \textbf{Welch's t-test:} 19,505 probes selected.
    \item \textbf{ANOVA F-test:} 19,540 probes selected.
    \item \textbf{SVM-RFE:} 20 probes selected.
    \item \textbf{Random-Forest importance:} 20 probes selected.
    \item \textbf{LASSO:} 20 probes selected.
\end{itemize}

This behavior is consistent with the implementation. The filter methods retain all probes whose univariate association reaches the chosen threshold, whereas the wrapper and embedded methods are constrained to a compact subset by design. In other words, the p-value threshold changes the interpretation of the filter results: the selected set is no longer a tiny top-$20$ shortlist but a broad statistical signal set.

\section{Interpretation of the Selection Patterns}

The contrast between the filter and the wrapper/embedded results provides the main insight of this chapter. The filter methods are conservative in a statistical sense, but they are not sparse by construction; a permissive threshold can still leave thousands of probes in the selected set. By contrast, the wrapper methods and LASSO produce a small, interpretable subset that is more suitable for downstream modeling and biological interpretation.

This distinction matters for the manuscript narrative. The thesis is no longer framed around a fixed top-20 gene list for all methods. Instead, it emphasizes the selection rule itself: the user can choose either a p-value threshold for a broader, statistically driven set or a target size such as 20 for a compact subset. The full ranked feature lists and selected gene names for each method are stored in the project result files under the results directory.

\section{Practical Relevance}

The updated analysis demonstrates that feature selection remains essential for this type of genomic classification problem, but it also shows that the choice of selection rule strongly affects the size and nature of the selected feature set. A filter method with a relaxed threshold produces a broad candidate set, while a wrapper or embedded method produces a sparse feature subset that is easier to interpret and use in subsequent classifiers.

The project therefore treats feature selection as a tunable analysis step rather than as a single fixed procedure.
