\chapter{METHODOLOGY}

\section{Dataset Description}

The analysis used the two GEO datasets registered in the preprocessing pipeline: GSE19804 and GSE42568. The primary feature-selection workflow was carried out on GSE19804, a balanced lung-cancer dataset, while GSE42568 was retained as a secondary benchmark for the SVM evaluation chapter. Both datasets contain the same high-dimensional structure characteristic of microarray studies:

\begin{itemize}
    \item \textbf{GSE19804:} 120 samples (60 cancer, 60 normal) and 54,675 probes.
    \item \textbf{GSE42568:} 121 samples (104 cancer, 17 normal) and 54,675 probes.
    \item \textbf{Data type:} bulk expression values from Affymetrix-style microarray experiments.
\end{itemize}

The inclusion of both datasets makes it possible to study feature-selection behavior under different class-balance regimes while keeping the same preprocessing and modeling framework.

\section{Data Preprocessing and Normalization}

Raw gene-expression values are typically right-skewed and contain substantial measurement noise. We therefore applied a two-step preprocessing pipeline before any feature selection or classification step:

\subsection{Log2 Transformation}

Each expression value $x$ was transformed as
\begin{equation}
    y = \log_2(x + 1).
\end{equation}

This stabilizes variance, reduces skewness, and makes the data more suitable for parametric statistical tests and linear models.

\subsection{Standardization (Z-score Normalization)}

After the log transformation, each feature was standardized across samples:
\begin{equation}
    z = \frac{x - \mu}{\sigma},
\end{equation}

where $\mu$ and $\sigma$ denote the feature mean and standard deviation. Standardization is particularly important for regularized methods such as LASSO and for SVMs, because it prevents features with large absolute values from dominating the optimization objective.

\section{Feature Selection Methods}

We compared three families of feature-selection strategies: filter, wrapper, and embedded methods. All selectors were fit inside each training fold of cross-validation so that feature selection could not leak information from the held-out data.

\subsection{Filter Methods}

\subsubsection{Welch's Independent Two-Sample T-Test}

For each probe $j$, we computed the Welch $t$-statistic comparing cancer and normal samples:
\begin{equation}
    t_j = \frac{\bar{x}_{c,j} - \bar{x}_{n,j}}{\sqrt{\frac{s_{c,j}^2}{n_c} + \frac{s_{n,j}^2}{n_n}}},
\end{equation}

where $\bar{x}_{c,j}$ and $\bar{x}_{n,j}$ denote the sample means in the cancer and normal groups, and $n_c$ and $n_n$ are the corresponding sample sizes. The resulting $p$-values were used to rank probes.

\textbf{Selection rule:} To standardize subset size while ensuring statistical significance, the filter methods combine $p$-value filtering with a top-$k$ cap ($k=20$). Probes are first filtered to retain only those with $p \leq \alpha$ ($\alpha = 0.05$). If more than $k$ probes satisfy this threshold, they are ranked by significance ($p$-value ascending or $F$-statistic descending) and capped at the top $k=20$ probes. This ensures that all feature selection methods (filter, wrapper, and embedded) yield consistent, directly comparable $k=20$ feature subsets.

\subsubsection{ANOVA F-Test}

The ANOVA F-test evaluates whether the between-group variance exceeds the within-group variance for each probe. Probes with larger F-scores and smaller associated $p$-values are treated as more discriminative. As with Welch's $t$-test, the ANOVA filter applies the combined $p \leq 0.05$ significance constraint and top-$k=20$ ranking rule.

\subsubsection{BH-FDR Ranked Filter}

The final filter variant used in the project implements a Benjamini-Hochberg (BH) false-discovery-rate control step before ranking. For each probe, the pipeline first computes the ANOVA F-statistic and associated $p$-value, then applies BH adjustment to the full probe set. Features with adjusted $p$-value $q \leq 0.05$ are retained, and the survivors are ranked by a combined score formed from the percentile ranks of:

\begin{itemize}
    \item ANOVA F-score,
    \item Cohen's $d$ effect size, and
    \item mutual information between probe expression and class label.
\end{itemize}

The combined ranking is the arithmetic mean of the three percentile ranks, and the top $k$ probes are selected from this filtered pool. This makes the FDR-ranked selector more conservative than the raw univariate filters: it does not simply take the strongest $k$ unadjusted features, but instead requires statistical evidence after multiple-testing correction before a probe is considered competitive.

\subsubsection{Within-Fold Resampling for Imbalanced Training}

For the imbalanced breast-cancer benchmark (GSE42568), the training split was further adjusted with a fold-protected resampling step. Synthetic Minority Over-sampling Technique (SMOTE) was applied only after feature selection on the training fold and strictly never on the held-out test fold. This avoids leakage while increasing the effective number of minority-class samples in the training data. The implementation uses the standard SMOTE variant with $k_{\text{neighbors}} = 5$, with a guard that clamps the neighbor count to the available minority-class count in a fold so that very small training folds do not fail during resampling.

\subsubsection{Threshold Tuning from Decision Scores}

The classification threshold was not fixed at the default value $0.5$ for the imbalanced analyses. Instead, after a classifier was trained, the decision-function scores from the training-fold predictions were used to select the threshold that maximized Youden's $J$ statistic:

\begin{equation}
    J = \text{Sensitivity} + \text{Specificity} - 1.
\end{equation}

This thresholding step was computed from the raw decision-function values rather than from probability estimates, avoiding the additional Platt-scaling cross-validation that would otherwise be triggered by setting the SVM to use \texttt{probability=True}. The same underlying decision score is also used to report the default-threshold and tuned-threshold comparisons for the imbalanced dataset.

\subsubsection{Nested Tuning of $k$ and $C$}

Two additional model-selection steps were added for the imbalanced setting. First, the subset size $k$ was swept over $\{10, 20, 50, 100\}$ inside an inner cross-validation loop, and the value maximizing mean MCC was retained for the outer evaluation. Second, the SVM regularization parameter $C$ was tuned with a compact inner-CV search over $\{0.01, 0.1, 1, 10, 100\}$, while comparing class-weight settings of either \texttt{None} or \texttt{"balanced"}. This keeps the SVM optimization consistent with the class-imbalance problem without expanding the experimental design into an unnecessarily expensive double-nested loop beyond the required model-selection steps.

\subsection{Wrapper Methods}

\subsubsection{SVM-RFE and Random-Forest Importance}

Wrapper methods were implemented with an ANOVA-based prefiltering step. In each training fold, the pipeline first computes ANOVA statistics and retains a reduced candidate set before any wrapper search begins. This step is important for two reasons: it makes the wrapper search computationally tractable on tens of thousands of probes, and it removes features with weak univariate signal before a multivariate model is fit.

The retained candidate set is then passed to either:
\begin{itemize}
    \item \textbf{SVM-RFE}, which repeatedly removes the least important features according to a linear SVM, or
    \item \textbf{Random-Forest importance}, which ranks probes by impurity reduction.
\end{itemize}

Greedy forward and backward selection were removed from the implementation because they required orders of magnitude more model fits and were not competitive in this high-dimensional setting.

\subsection{Embedded Methods}

\subsubsection{LASSO (L1-Regularized Logistic Regression)}

The embedded selector uses L1-regularized logistic regression. The model minimizes a penalized logistic-loss objective and forces many coefficients to zero, yielding a sparse set of selected probes. In the implementation, the regularization strength is selected by cross-validated logistic regression over a grid of inverse-regularization values $C$; smaller values of $C$ imply stronger regularization. If the cross-validated fit fails, the code falls back to a fixed-$C$ LASSO model.

\section{Evaluation Metrics}

The selected feature subsets were assessed with the Matthews Correlation Coefficient (MCC), accuracy, precision, recall, F1-score, and ROC-AUC when applicable. MCC was used as the main summary metric because it remains informative for imbalanced datasets and does not inflate performance when one class dominates the sample distribution.

\subsection{Cross-Validation Strategy}

A 5-fold stratified cross-validation strategy was used throughout the study. This procedure preserves the class distribution within each fold, provides a more stable estimate of generalization performance, and reduces the chance that a single split dominates the results.

\section{Comparative Analysis of Selected Feature Sets}

The project compares feature sets not only by predictive performance but also by overlap across methods. Because the filter methods can retain a large number of probes when a permissive p-value threshold is used, overlap is interpreted as a qualitative measure of stability rather than as a strict top-$k$ comparison. The generated summary files store the full selected feature lists for each method and dataset, making the comparison reproducible.
